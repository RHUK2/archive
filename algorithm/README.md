# 알고리즘 • 자료구조

TypeScript(`.mts`)로 작성한 구현 모음이다. 문서가 아니라 실행 가능한 코드가 주력이라 다른 폴더와 성격이 다르다.

| 폴더 | 내용 |
| --- | --- |
| [dataStructure](dataStructure) | Stack, Queue, PriorityQueue, SinglyLinkedList, DoublyLinkedList, HashTables, BinarySearchTree, Heap, Graph. [빅오 표기법 정리](dataStructure/bigO.md) 포함 |
| [sort](sort) | bubble, insertion, selection, merge, quick, radix |
| [search](search) | linear, binary, string |
| [frequency_counters](frequency_counters) | validAnagram, sameFrequency, areThereDuplicates |
| [multiple_pointers](multiple_pointers) | averagePair, isSubsequence, countUniqueValues, areThereDuplicatesPointer |
| [sliding_window](sliding_window) | maxSubarraySum, maxSubarrayLen, findLongestSubstring |
| [reculsive](reculsive) | factorial, fib, power, reverse, isPalindrome, productOfArray, recursiveRange |

자료구조 폴더의 `.excalidraw` 파일은 각 구조의 도식이다. GitHub에서 클릭하면 바로 렌더링된다.

`helper.mts`는 공용 유틸, `template.md`는 문제 풀이 템플릿이다.
